### 기입 규칙 (빈칸을 채울 때)

- **모델명**: 도구 UI에 표기된 정확한 문자열을 그대로 적는다. "AI"라고만 쓰지 않는다.
- **생성일**: `YYYY-MM-DD`.
- **프롬프트 요지**: 실제로 넣은 프롬프트의 핵심. 요약해도 되지만 **양식·색·캔버스 크기는 반드시 포함**한다.
- **이용약관 URL / 확인일**: 생성물의 상업적·공개적 이용 가부가 적힌 페이지. **확인일을 반드시 적는다** —
  약관은 개정되고, "언제 시점의 약관을 근거로 썼는지"가 우리가 방어할 수 있는 전부다.
- 파일이 끝내 생성되지 않으면 **행을 지우지 말고** 「미생성 — 코드 도형 폴백 사용」이라고 적는다.
  실제로 안 쓴 에셋을 썼다고 적는 것도 허위 기재다.

### 양식 통일 방법 (참고 이미지 정책)

**상용 게임 스크린샷을 레퍼런스로 첨부하지 않는다.** 대신 ①번 생성물(`player.png`)을 완성한 뒤
②~⑥의 생성에 **그 이미지를 레퍼런스로 첨부**해 양식을 통일한다.
타인의 저작물이 생성 과정에 개입할 여지를 없애기 위한 조치다(하네스 11·12).

## 3. 폰트

**폰트 파일을 도입하지 않는다.** 시스템 `sans-serif`만 사용한다(GDD §9-5).
→ 폰트 라이선스 이슈가 원천적으로 발생하지 않는다.
